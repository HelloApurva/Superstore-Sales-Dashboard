## 📌 Project Overview

The **Superstore Sales Dashboard** is an interactive Power BI dashboard designed to analyze retail sales performance across different regions, customer segments, product categories, and time periods. The dashboard transforms raw sales data into meaningful business insights through dynamic visualizations and key performance indicators (KPIs).

This project demonstrates the use of **Power BI**, **Power Query**, and **DAX** to build an intuitive business intelligence solution for sales analysis.

---

## 🎯 Project Objective

The dashboard aims to:

- Monitor overall sales and profit performance
- Analyze customer segments and purchasing behavior
- Evaluate product category performance
- Compare regional sales trends
- Support business decision-making using interactive visualizations
